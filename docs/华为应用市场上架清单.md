## 线路 1：域名 + 备案 + HTTPS

### 1.1 注册域名【你做 · 10 分钟】

- 去 https://www.huaweicloud.com/product/domain.html
- 搜索 `.top` 域名，推荐 `keeplit.top`（首年约 8 元）
- 备选：`keeplit-app.top`、`xide-campus.top`
- 注册时同步完成 **域名实名认证**（需身份证）
- 记录域名：`____________________.top`

### 1.2 DNS 解析配置【你做 · 5 分钟】

- 华为云控制台 → DNS 云解析 → 添加解析记录
- A 记录：`@` → `1.94.195.90`
- A 记录：`www` → `1.94.195.90`（可选）

### 1.3 提交 ICP 备案【你做 · 30 分钟填表 + 1-2 周审核】

- 华为云控制台 → 备案中心 → 新增备案
- **备案主体**：填你本人真实信息（姓名、身份证、手机号）
- **网站信息**：
  - 域名：你注册的域名
  - 服务类型：网站类
  - 内容类型：教育
  - 服务器：选择你的 ECS（cn-north-4）
- 提交后华为云客服会电话核实，接电话确认即可
- 审核通过后拿到 **ICP 备案号**
- ⚠️ 备案通过前域名无法正常访问

### 1.4 申请 SSL 证书【你做 · 备案通过后 · 10 分钟】

- 华为云控制台 → SSL 证书管理 → 购买证书
- 选择 **免费 DV 证书**（0 元）
- 域名填你的域名，验证方式选 DNS 验证
- 几分钟后签发完成，下载 Nginx 格式（`.crt` + `.key`）

### 1.5 信息记录

```
域名：           ____________________.top
ICP 备案号：      ____________________
HTTPS 地址：     https://____________________.top
```

## 线路 2：本地编译 HAP

### 2.1 安装 DevEco Studio【你做 · 30 分钟】

- 下载：https://developer.huawei.com/consumer/cn/deveco-studio/
- 版本要求：**5.0 及以上**
- 安装时勾选 HarmonyOS SDK（API 12）

### 2.2 打开工程【你做 · 10 分钟】

- DevEco Studio → Open Project → 选择 `mobile-harmony` 目录
- 等待 hvigor 同步完成
- 如 SDK 版本不匹配：File → Project Structure → 改为 5.0.0(12)

### 2.3 配置签名【你做 · 15 分钟】

#### 调试签名（自动）
1. File → Project Structure → Signing Configs
2. 勾选 **Automatically generate signature**

#### 发布签名（手动，上架用）
1. 登录 AppGallery Connect → 用户与访问 → 证书管理
2. 新建证书 → 上传 `.csr` → 下载 `.cer`
3. 回到 DevEco → Signing Configs → 配置 Release：
   - Store File：`.p12` 路径
   - Store Password：你设的密码
   - Key Alias / Key Password
   - Sign Alg：SHA256withECDSA
   - Profile File：从 AGC 下载的 `.p7b`
   - Certpath File：下载的 `.cer`

### 2.4 修改 BASE_URL【你做 · HTTPS 好后 · 1 分钟】

打开 `entry/src/main/ets/net/Api.ets`，改：
```typescript
// 改前
export const BASE_URL: string = 'https://xide.example.com';
// 改后
export const BASE_URL: string = 'https://你的域名.top';
```

### 2.5 编译 HAP【你做 · 5 分钟】

#### Debug（先跑通）
1. 连接 HarmonyOS 真机或模拟器
2. Run → Run 'entry' → 测试登录 + 5 Tab

#### Release（上架用）
1. Build → Build Hap(s)/APP(s) → Build Hap(s)
2. 产物：`entry/build/default/outputs/default/entry-default-signed.hap`
3. ⚠️ 确认 BASE_URL 已改成 HTTPS 域名

## 线路 3：ECS 服务器配置

### 3.1 安装 Nginx【可代做 · 5 分钟】

```bash
sudo apt update && sudo apt install -y nginx
```

### 3.2 配置 Nginx 反向代理【可代做 · 10 分钟】

创建 `/etc/nginx/sites-available/keeplit`：
```nginx
server {
    listen 80;
    server_name 你的域名.top;
    location / {
        proxy_pass http://127.0.0.1:5820;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
# SSL 证书到位后加 443 server 块（见 3.3）
```

启用：
```bash
sudo ln -s /etc/nginx/sites-available/keeplit /etc/nginx/sites-enabled/
sudo rm /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
```

### 3.3 部署 SSL 证书【你做 · 证书签发后 · 5 分钟】

本地执行：
```bash
scp 你的域名.crt root@1.94.195.90:/etc/nginx/ssl/
scp 你的域名.key root@1.94.195.90:/etc/nginx/ssl/
```

ECS 上追加 443 配置：
```nginx
server {
    listen 443 ssl;
    server_name 你的域名.top;
    ssl_certificate     /etc/nginx/ssl/你的域名.crt;
    ssl_certificate_key /etc/nginx/ssl/你的域名.key;
    location / {
        proxy_pass http://127.0.0.1:5820;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

验证：`curl -I https://你的域名.top` → 应返回 200

### 3.4 安全组放行 443 端口【可代做 · 2 分钟】

- 华为云控制台 → ECS → 安全组 → 入方向规则
- 添加：TCP 443，源地址 0.0.0.0/0
- 同时确认 80 端口已放行

### 3.5 Flask 开机自启【可代做 · 5 分钟】

```bash
sudo tee /etc/systemd/system/keeplit.service > /dev/null << 'EOF'
[Unit]
Description=KeepLit Flask App
After=network.target
[Service]
Type=simple
User=root
WorkingDirectory=/opt/keeplit
ExecStart=/usr/bin/gunicorn -w 4 -b 127.0.0.1:5820 app:app
Restart=always
RestartSec=5
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable keeplit && sudo systemctl start keeplit
```

1. 登录 https://developer.huawei.com/consumer/cn/agconnect/
2. 我的应用 → 创建应用 → 平台选 **HarmonyOS**

### 4.5 常见驳回原因

| 原因 | 解决 |
|------|------|
| 未配置 HTTPS | 完成 1.4 + 3.3 |
| 隐私政策无法访问 | 确认 URL 可打开 |
| 应用崩溃 | 真机完整测试 |

| 截图不清晰 | 真机 1080p 截图 |

| 权限未声明 | 检查 module.json5 |
