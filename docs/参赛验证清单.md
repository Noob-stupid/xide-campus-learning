## C. 华为云部署（⚠️ 必做，最小闭环约 2 小时）

> 当前代码只支持 **SQLite + 本地文件**。RDS/Redis/OBS 是文档规划，代码未接入，不能勾“已验证”。

### C1 ECS + Docker（推荐）

> 仓库已提供 `.dockerignore`，不会把 `.env`、`.codearts-agent.env`、`data/` 打进镜像。

```bash
# 宿主机准备（模型配置写在 /opt/xide/.env，不要依赖 .codearts-agent.env 进镜像）
mkdir -p /opt/xide/data
cp .env /opt/xide/.env
# 在 /opt/xide/.env 里补：ZX_SECRET_KEY / ZX_COOKIE_SECURE=1 / ZX_LLM_BASE_URL / ZX_LLM_API_KEY / ZX_LLM_MODEL

docker build -t xide .
docker run -d --name xide -p 5820:5820 \
  -v /opt/xide/data:/app/data \
  --env-file /opt/xide/.env \
  xide

# 首次：挂载的是空目录，需在容器内重新 seed
docker exec xide python seed.py --reset
```

- [ ] 通过：`curl http://127.0.0.1:5820/api/health` 返回 `{"ok":true,"service":"xide"}`
- [ ] 注意：不挂载 `/app/data` 时，容器重建会丢数据；挂载空目录时必须执行上面的 seed
- [ ] 注意：`.codearts-agent.env` 被 `.dockerignore` 排除，容器内不会自动读取；模型配置通过 `--env-file` 注入
