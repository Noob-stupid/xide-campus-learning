# 习得 · UI 设计说明

## 1. 原则

- **保留原布局**：深色侧栏、顶栏、卡片网格、页面结构不动；只改视觉。
- **校园导视，不是 AI 仪表盘**：冷灰蓝底、深海军蓝、信号橙，像图书馆索引牌和路标。
- **不用模板化 AI 视觉**：不用暖纸 + 衬线 + 陶土，不用渐变光晕、霓虹、玻璃拟态。
- **一个作品，不是三个模块**：全站一套导航、一套文案、一套视觉。
- **按钮有反馈**：不可用动作不摆灰按钮；点击有 toast 或状态变化。

## 3. 布局

- 布局完全沿用原版：桌面深色侧栏 + 顶栏 + 内容区；移动端沿用原响应式导航。
- 顶栏右侧：消息、用户、退出登录；移动端隐藏顶栏退出，退出入口放在「我的」页。
- 不移动、不缩放、不重排任何页面模块。

## 5. 三个差异化组件

1. **接棒卡**：结束后的核心物件，带“为什么推给你”和复核签章。
2. **一屏帧级审核工作台**：左预览、中帧时间轴（红帧）、右 AI 理由 + 四项清单 + 通过/驳回。
3. **编排流水线看板**：五条流的节点图 + 运行轨迹 + 指标。

## 6. 文案口径

- 上传 → **交棒**；收到推送 → **接棒**；内容池 → **接力池**。
- 不说“全自动审核”，说“AI 初筛 + 人工帧级复核”。
- 不说“猜你喜欢”，说“为什么推给你”。
- 不出现粉丝、获赞、热门等社交词。

## 7. 多建筑/多楼层

- 选座页顶部两步：**① 选择地点**（建筑下拉 + 楼层 Tab）→ **② 选择座位**（座位图）。
- 切换楼层自动加载该层座位、区域标签与路网；预约/导航带楼层信息。
- 演示数据：图书馆 2F、图书馆 3F、教学楼 A 1F。

## 8. 个人主页与退出

- 头像：点击头像上传，支持 jpg/png/webp/gif、≤ 8MB。
- 封面：点击封面或「更换封面」上传；个人主页顶部展示。
- 资料：昵称、学院、学习签名、兴趣方向。
- 头像同步到侧栏与顶栏。
- 退出登录：桌面顶栏「退出」；移动端「我的」页「退出登录」。

## 9. 室外导航

- 校门 / 当前位置 → 图书馆 / 教学楼 A；显示距离、方向、步行时间与分步指引。
- 已配置高德 JS Key 时尝试加载高德地图与步行路线；失败自动回退相对方向示意图。
- 到馆后切换到室内导航，继续选楼层与座位。

## 10. 样式文件

- `static/css/app.css`：基础布局与组件。
- `static/css/editorial.css`：只覆盖颜色、字体、边框、阴影与组件质感；不写 width/height/grid/padding 等布局属性。
- 参考：`anthropics/skills` 仓库的 `frontend-design` skill（GitHub 热门前端设计 skill）。
