# 习得 · UI 设计说明

## 1. 原则

- **上一版布局 + 视频站式侧栏**：保留深色主视觉与内容卡片；左侧栏改为白底、B 站蓝选中态、圆角导航项；不要 AI 紫、霓虹、赛博大屏。
- **一个作品，不是三个模块**：全站一套设计系统、一套导航、一套文案。
- **详细精简**：提示把信息说全，但不堆废话。
- **按钮有反馈**：不可用动作不摆灰按钮；任何点击都有 toast / 状态变化。
- **响应式**：桌面左侧导航，移动端底部 Tab；座位图可缩放（浏览器手势）。

## 4. 从两个原 Web 项目吸收了什么

### ✓ 采用（只借观感/交互，全部重写）

- 视频站个人主页：封面 + 头像 + 数据栏 + Tab + 卡片网格；数据换成学习场次/专注时长/交棒/接棒/有帮助率。
- 视频站播放页/上传页：播放器、上传进度、审核状态。
- 视频站待审列表：队列、通过/驳回、驳回原因。
- 智座座位图：状态色、点座位看详情、筛选。
- 智座导航：路径、距离、步行时间、步骤列表。
- 智座 AI 推荐理由：推荐座位/接棒都写“为什么”。
- 智座终端：科技简约、克制，只借气质。

### ✗ 不采用

- 轮播图、五大分类频道、热门榜、点赞/收藏/评论/关注/动态/私信。
- 粉丝/获赞/浏览等社交指标。
- Vue3 + Element Plus + Fabric.js + ECharts + Socket.IO 重前端栈。
- 整套建筑/楼层/座位/设备/用户/学校管理后台。
- 室外导航、高德地图、移动端 App、语音/扫码/PDR/地理围栏。
- 任何 `E:\项目\...` 硬编码、mock-api 兜底、页面级独立 CSS/JS。

## 5. 三个差异化组件

1. **接棒卡**：结束后的核心物件，像票根/登机牌；带“为什么推给你”和复核签章。
2. **一屏帧级审核工作台**：左预览、中帧时间轴（红帧）、右 AI 理由 + 四项清单 + 通过/驳回。
3. **编排流水线看板**：五条流的节点图 + 运行轨迹 + 指标。

## 6. 文案口径

- 上传 → **交棒**；收到推送 → **接棒**；内容池 → **接力池**。
- 不说“全自动审核”，说“AI 初筛 + 人工帧级复核”。
- 不说“猜你喜欢”，说“为什么推给你”。
- 不出现粉丝/获赞/热门等社交词。

## 7. 多建筑/多楼层与退出登录

- 空间页顶部：建筑下拉 + 楼层 Tab + 当前楼层标签；切换楼层自动重载座位图与路网。
- 演示数据：图书馆 2F（48 座）、图书馆 3F（16 座）、教学楼 A 1F（15 座）。
- 导航页显示建筑/楼层/座位，路径按该层路网计算。
- 顶栏右侧「退出」按钮：调用 `/api/auth/logout`，回到登录页。
