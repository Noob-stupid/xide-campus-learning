# 习得 · Web 与鸿蒙双端说明

## 一句话

**Web 是评委打开的桌面作品；鸿蒙 App 是校园现场用的移动端，不是把 Web 改成手机版。**

## 两端边界

| | Web 版 | 鸿蒙 App |
|---|---|---|
| 入口 | 浏览器打开公网 URL | 手机/模拟器安装 HAP |
| 布局 | 深色侧栏 + 顶栏 + 桌面卡片网格 | 底部 5 Tab：今日/空间/学习/接力池/我的 |
| 代码 | `templates/` + `static/` | `mobile-harmony/`（ArkTS/ArkUI） |
| 作用 | 评委看完整闭环、审核台、编排 | 学生现场找座、学习、接棒 |
| 后端 | 同一个 Flask API | 同一个 Flask API |

## 不要混在一起

- 不要把 Web 模板改成底部 Tab 的手机版；
- 不要把鸿蒙 ArkUI 页面塞进 Web；
- Web 的响应式断点只是浏览器适配，不代表产品形态变成移动端；
- 只有 HAP 内部使用移动端布局。
