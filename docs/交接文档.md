## 1. 项目定位

「习得」把高校图书馆/自习室的三个割裂问题收束到**一次学习场次**上：

- 找座难：选座页先选地点（建筑 + 楼层），再选座位；
- 学习与内容脱节：结束/到期后，按学科、卡点、时长匹配已过审视频；
- 内容合规：学生/教师交棒视频必须经过 AI 初筛 + 人工帧级复核。

核心记忆点：

- **交棒 / 接棒 / 接力池**：上传叫交棒，收到推送叫接棒；
- **接棒卡**：带匹配理由与复核签章；
- **一屏帧级复核**：AI 只标疑点，人只拍板可疑帧；
- **结束即服务**：离座不是结束，是下一条学习视频的开始。

## 12. 迁移到 CodeArts / 云上 Agent 的步骤

### 12.1 代码导入

1. 在 CodeArts 创建仓库/导入 `zhixue-space`；
2. 确认 Python 3.12+、安装 `requirements.txt`；
3. 跑 `python seed.py --reset && python -m pytest -q`，确认 78 passed；
4. 用 `python app.py` 或 Docker 起服务，先跑通本地演示。

### 12.2 RDS MySQL

- 新建 RDS MySQL 实例/库 `xide`；
- 把 `db.py` 的 SQLite schema 迁到 MySQL：
  - `INTEGER PRIMARY KEY AUTOINCREMENT` → `BIGINT AUTO_INCREMENT PRIMARY KEY`；
  - `REAL` → `DOUBLE`；
  - `TEXT` 保留 `TEXT/LONGTEXT`；JSON 字段（score_json/payload/features）可改 `JSON`；
  - 时间字段当前是 `TEXT` ISO 字符串；迁移时统一 `DATETIME` 或继续字符串，**不要混用**；
  - 加唯一索引：`users.username`、`seats(floor_id,code)`、`buildings.name`；
  - 预约冲突查询加索引：`reservations(seat_id,start_at,end_at)`。
- 把 `db.py` 的连接层换成 PyMySQL/SQLAlchemy；保留 `query/one/execute/executemany` 接口，减少业务改动；
- 预约写入用事务 + `SELECT ... FOR UPDATE`。

### 12.3 Redis

| 用途 | Key | 建议 |
|---|---|---|
| 抢座锁 | `seat:lock:<seat_id>:<slot>` | `SET NX EX 10`，Lua 比对 token 释放 |

## 17. 常见坑

1. **seed --reset 会清空数据**：演示前先跑；不要把真实数据放 `data/zhixue.db` 后随意 reset。
2. **`data/` 被 gitignore**：迁移时要么 copy `data/`，要么重新 seed；媒体文件不会随 git 走。
3. **模板缓存**：改 `templates/` 后 Flask 进程可能缓存；重启 `python app.py` 再截图。
4. **端口占用**：`Get-NetTCPConnection -LocalPort 5820` 查进程；停掉旧进程再起。
5. **中文路径 + OpenCV**：写帧用 `cv2.imencode(...).tofile()`，不要直接 `cv2.imwrite` 中文路径。
6. **演示登录**：`/demo-login/<name>` 只在 `ZX_DEMO_LOGIN=1` 时可用；生产关闭。
7. **接棒幂等**：同一 session 只推一次；测试时想重推要清 `relay_pushes` 或换 session。
8. **封面点击区域**：已改为整块封面可点 + 操作区「更换封面」大按钮；改 UI 时不要缩小点击区域。
9. **头像/封面**：存 `data/media/profiles/`，DB 存相对路径 `profiles/...`；`media_url()` 负责转 URL。
10. **室外坐标**：是演示坐标，不要当真实校园测绘结果。
