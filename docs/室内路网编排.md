# 室内路网编排（后台）

> 对应页面：管理员「地图」(`/admin/maps`)。数据表：`nav_nodes` / `nav_edges` / `seats` / `floors.plan_path`。
> 参考项目：[smart-seat-selection-nav](https://github.com/Noob-stupid/smart-seat-selection-nav)（只借鉴了能力与算法思路，代码按本仓库的表结构和主题重写）。

## 1. 解决什么问题

改造前，后台只能上传楼层底图，座位和路网的坐标写死在 `seed.py` 里：

- 上传一张真实平面图后，座位牌按老的网格坐标摆放，**和图对不上**；
- 路网（A\* 用的 `nav_nodes` / `nav_edges`）只能靠种子脚本生成，**不能在图上编辑**；
- 没有 DXF 导入，也没有连通性检查。

现在这些都在后台一次做完：底图、座位、路网共用同一张 **960×620** 画布，所见即所选。

## 2. 现在能做什么

| 能力 | 说明 |
| --- | --- |
| 座位：新增 | 「座位」图层 + 「点空白新增」，在底图上点一下就落一个座位（自动编号 `S-xx`，可改） |
| 座位：拖动 | 直接拖，10px 吸附（可关） |
| 座位：属性 | 座位号 / 区域 / 类型（普通·靠窗·有电源·静音·讨论）/ 标签 |
| 座位：多选批量删 | Shift 点选多个 → 批量删除；有未结束预约的座位会被拒绝并返回名单 |
| 路网：节点 | 「路网」图层点空白加节点（`N001` 起），可拖、可改编号与类型（走廊/入口/路口/楼梯） |
| 路网：连线 | 选中节点 → 「从这里连线」 → 点另一个节点；重复连线会提示 |
| 路网：删除 | 删节点会连它的边一起删；也可「清空路网」重来 |
| 路网：诊断 | 连通分量数、最大连通率、孤立点、末端节点、越界点、重复边，并给出中文建议 |
| 路网：接断点 | 一键把断开的多块按「最近的一对节点」连起来（上限 140–160px） |
| **从底图生成** | 二值化 → 障碍掩膜 → 可行走区 → Zhang-Suen 细化 → 骨架聚类成图 → 剪毛刺 + 合并直线 → 自动接断点 |
| **DXF 生成** | 解析 ASCII DXF：按图层名识别 `wall/墙`、`furn/家具`、`text/房间名`；墙线铺路网，家具出座位候选，文字出房间名 |
| 整体拖路网（图上） | 「整体拖路网」模式下按住图面拖动，**只挪路网，座位不动**（自动生成常整体偏一点），松手保存；整组平移，**形态严格保持** |
| 整体调整（数值） | 整层缩放（0.4–2.5 倍）+ X/Y 平移；方向键 1px 微调（Shift 10px） |
| 视图 | 滚轮缩放（以鼠标为锚点）、右键/Alt 拖动平移、「适应」复位 |
| 画布尺寸 | **跟着底图比例走**：短边不小于 620（竖图宽不小于 960），底图不会被压扁；
  上传新底图比例变了，已有座位/路网按比例重映射；学生端选座页/导航页同步用同一画布 |
| 底图 | 上传 / 删除，PNG·JPG·WebP ≤12MB |

| 地点 / 楼层 | 「＋ 新建」填地点名（如 图书馆、实验楼 B）+ 楼层名 + 楼层号；地点按名字自动建档 |
| 楼层整理 | 按地点分组、可折叠；顶部搜索框按地点名/楼层名过滤；行内「改名 / 删除」 |
| 删除守卫 | 楼层里还有座位时不允许删；删空楼层会连带清掉它的路网与底图文件 |

### 整体平移为什么不改形态

早期实现是逐个节点 `clamp` 到画布内，贴边的点各自被压回去 —— 拖到边缘路网就被压扁。
现在先把所有点按同一 `scale + dx/dy` 算好，再用**同一个**平移量把整组收进画布：
任何一个点都不会被单独挪动，点与点的距离保持不变（自动化测试逐对校验距离）。
另外拖拽时给画布做了 `setPointerCapture`，鼠标移出画布再松手也能收到 `pointerup` —— 否则这次拖动不会保存，看起来就像“弹回原位”。

### 画布尺寸怎么定

`floors.canvas_w / canvas_h`（老库自动补列，默认 960×620）：

| 底图比例 | 画布 |
| --- | --- |
| 宽图（w/h ≥ 1） | 高固定 620，宽 = max(960, 620×比例) |
| 竖图（w/h < 1） | 宽固定 960，高 = max(620, 960÷比例) |

底图用 `preserveAspectRatio=none` 铺满画布也不会变形，因为画布比例与图片一致。
上传新底图时若画布比例变化，已有座位与路网节点按 `新/旧` 比例整体重映射，相对位置不变。

## 3. 接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/admin/floors/<fid>/network` | 读节点、连线、统计 |
| POST | `/api/admin/floors/<fid>/nodes` | 新增节点 `{x,y,kind?,code?}` |
| PUT | `/api/admin/nodes/<nid>` | 改节点（坐标/编号/类型；改编号会同步边） |
| DELETE | `/api/admin/nodes/<nid>` | 删节点及关联边 |
| POST | `/api/admin/floors/<fid>/edges` | 连线 `{from_node,to_node}`（自动算距离，查重） |
| DELETE | `/api/admin/edges/<eid>` | 删连线 |
| POST | `/api/admin/floors/<fid>/network/join` | 接上断开的分块 |
| DELETE | `/api/admin/floors/<fid>/network` | 清空路网 |
| POST | `/api/admin/floors/<fid>/transform` | 整体缩放平移 `{scale,dx,dy,with_seats}` |
| GET | `/api/admin/floors/<fid>/network/diagnose` | 结构化诊断 + 中文建议 |
| POST | `/api/admin/floors/<fid>/network/generate` | 用本层底图生成路网 |
| POST | `/api/admin/floors/<fid>/network/from-dxf` | 上传 DXF 生成 `file` + `apply_seats=1` |
| POST | `/api/admin/floors` | 新建楼层 `{building,name,floor_no}`（地点不存在会自动建档） |
| PUT | `/api/admin/floors/<fid>` | 改楼层（地点名 / 楼层名 / 楼层号） |
| DELETE | `/api/admin/floors/<fid>` | 删楼层（有座位则拒绝） |
| POST | `/api/admin/nodes/bulk-delete` | 批量删节点 `{ids:[...]}`（连带删边） |
| POST | `/api/admin/floors/<fid>/seats` | 新增座位 |
| PUT | `/api/admin/seats/<sid>` | 改座位（坐标/编号/区域/类型/标签） |
| DELETE | `/api/admin/seats/<sid>` | 删座位（有未结束预约则拒绝） |
| POST | `/api/admin/floors/<fid>/seats/bulk-delete` | 批量删 `{ids:[...]}`，返回被预约拦下的座位号 |

全部接口都是 `admin` 权限，坐标统一钳制在 960×620 画布内（边距 8px）。

## 4. 两条生成路线怎么选

| | 图片路线 | DXF 路线 |
| --- | --- | --- |
| 输入 | 底图 PNG/JPG | CAD 导出的 ASCII DXF |
| 依据 | 明暗对比「猜」墙线 | 图层名直接说明墙 / 家具 / 房间 |
| 产出 | 只有路网 | 路网 + 座位候选 + 房间名 |
| 典型结果 | 约 200–250 节点、300–400 边 | 视图纸规模，含 3~上百个座位候选 |
| 适用 | 没有 CAD 图、只想知道哪里能走 | 有正式图纸，想一次把座位也铺好 |

生成后会**自动接断点**（正交邻接会让骨架碎成几块），返回里带 `joined` 数量。

## 5. 算法要点（为什么要这些步骤）

1. **只连正交邻居**：骨架聚类后若按 8 邻接连边，会连出一堆三角形，路网像渔网，A\* 会在走廊里斜插。改成只连上下左右。
2. **剪毛刺 + 合并直线**：细化算法必然留下 1px 短枝；先反复删度=1 的叶子，再把度=2 且转角 <20° 的中间点合并掉。
3. **自动接断点**：正交邻接会让图分成几块；生成后按最近节点对连起来，保证连通率 100%。
4. **坐标系一致**：生成、座位、路网都用 960×620，DXF 按墙主体包围盒等比缩放并居中（`MARGIN=28`）。

## 6. 使用步骤（有 CAD 图）

1. 管理员 →「地图」，选楼层，先上传平面图（PNG/JPG，接近 4:3 最好）；
2. 「DXF 生成」选择 `.dxf`，勾选「同时写入座位候选」→ 生成后看统计与诊断；
3. 用「路网」图层检查：孤立点删掉、断开的用「从这里连线」或「接上断开的部分」补；
4. 用「座位」图层微调座位牌位置（拖动吸附）；
5. 如果底图和生成的坐标整体偏移，用「整体调整」输入平移量（方向键可 1px 微调），座位和路网会一起动；
6. 「诊断路网」确认连通率 100% 后，学生端「空间 → 选座 → 导航」即可按新路网寻路。

### 新建一个地点 / 楼层

1. 左栏「＋ 新建」→ 填地点（新名字自动建档，比如「实验楼 B」）、楼层名（如「3F 创新制造」）、楼层号；
2. 新楼层建好后自动选中，接着上传底图、摆座位；
3. 楼层多了：顶部搜「图书馆」，或点地点名前的箭头折叠整组。

### 多选删除

- **座位**：Shift 点选多个，属性面板出现「批量删除」；
- **节点**：在「路网」图层 Shift 点选多个节点 →「批量删除节点」（连线一起删）；
- 有未结束预约的座位不会被删，接口会返回被拦下的座位号。
- 路网整体偏移（自动生成常见）：切「整体拖路网」，按住图面拖一下，松手保存——座位和底图都不动。
- 拖动是 60fps 的：画布矩形缓存 + requestAnimationFrame 合帧，拖节点只重绘该节点和它两条线。

## 7. 已知限制

- 只解析 **ASCII DXF**；二进制 DXF 会提示不支持。图层名里要能看出 `wall/墙` 或 `furn/家具`，否则会退化成"所有线都当墙"。
- 图片路线只能猜可行走区，家具内部也可能被当成可走（骨架会穿进桌子）；有 DXF 时优先用 DXF。
- 生成会**覆盖**整层路网（座位不动，除非勾了写入候选）；操作前会二次确认。
- DXF 的座位候选编号是 `SEAT-001…`，落在区域 `CAD`，落库后可再改名。
