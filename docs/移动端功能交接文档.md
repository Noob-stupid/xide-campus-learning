## 0. 先看结论

### 推荐架构

**HarmonyOS HAP = 一个 `Web` 组件加载习得 HTTPS 页面 + `javaScriptProxy` 原生桥。**

原因：

- 赛道 1 的作品本体是 Web AI 创新应用，移动端是入口，不是第二套业务；
- 现有 Web 已有完整闭环，鸿蒙端重写全部页面成本高、容易双维护；
- 智座仓库的移动端也是 Hybrid（Capacitor 壳 + 云端 Web），不是纯原生；
- HarmonyOS 端只需要补齐：定位、通知、选文件、震动、状态栏、返回键、权限。

### 移动端首版范围

必须做（P0）：

1. 登录 / 退出 / 会话保持
2. 今日首页
3. 空间：先选建筑楼层，再选座位
4. 预约 + 室内 A* 导航 + 室外导航 + 签到
5. 学习：计时、卡住了辅导、结束学习、接棒卡、反馈
6. 我的：学习档案、头像/封面/昵称编辑

建议做（P1）：

7. 接力池
8. 交棒上传
9. 站内信

可暂不做（P2）：

10. 审核工作台、编排看板（桌面端更合适；手机可只读或隐藏）
11. 设备模拟器、管理端
12. 支付、社交、关注、评论

## 1. 移动端页面结构

### 底部 5 个 Tab

```
今日  |  空间  |  学习  |  接力池  |  我的
```

- 今日：问候、数据卡、当前场次、今日建议、最近接棒
- 空间：建筑/楼层选择 → 座位图 → 座位详情 → 预约
- 学习：计时、学习计划、卡住了辅导、接力卡
- 接力池：已过审内容卡片、学科筛选
- 我的：封面、头像、数据栏、5 个 Tab、编辑资料

### 页面栈

```
登录
 └─ 今日
     ├─ 空间 → 选地点 → 选座位 → 座位详情 → 预约 → 导航
     │                                      └─ 室内 / 室外
     ├─ 学习 → 卡住了辅导 → 接棒卡 → 反馈
     ├─ 接力池 → 内容详情 / 播放
     └─ 我的 → 编辑资料 / 换头像 / 换封面 / 学习名片
```

### 顶部栏

- 左：返回（非 Tab 根页）
- 中：页面标题
- 右：消息铃铛（未读数）
- 适配状态栏和安全区，不遮挡内容

## 2. 功能清单（按页面）

### 2.1 登录

| 功能 | 说明 |
|---|---|
| 账号密码登录 | `POST /api/auth/login` |
| 会话保持 | 保存 Cookie；重启 App 后仍登录 |
| 退出 | `POST /api/auth/logout` |
| 演示账号 | `student` / `reviewer` / `admin` / `teacher`，密码 `123456`（仅演示） |

### 2.2 今日

| 功能 | 说明 |
|---|---|
| 问候语 | 上午/下午/晚上 + 用户名 |
| 数据卡 | 空闲座位、今日场次、待复核、有帮助率 |
| 当前场次 | 有则显示计时和「进入学习」；无则显示「去找座位」 |
| 今日建议 | 3 条：看视频、50+10 节奏、推荐座位 |
| 最近接棒 | 最近一条接棒卡，点进详情 |
| 流水线 | 预约 → 签到 → 学习 → 结束 → 接棒 |

### 2.3 空间（核心）

**第一步：选地点**

- 建筑下拉/分段控件：图书馆、教学楼 A
- 楼层 Tab：2F 静学自习区、3F 研讨协作区、1F 自习室
- 切换楼层后重新加载该层座位和路网

**第二步：选座位**

- 座位图：SVG/Canvas，支持缩放、拖动、点选
- 状态色：空闲、已预约、使用中、维护
- 筛选：全部 / 靠窗 / 安静 / 电源
- 推荐座位：调后端推荐接口，展示推荐理由
- 座位详情底部弹窗：座位号、区域、类型、特性、状态
- 预约表单底部弹窗：学科、目标、开始/结束时间、快捷时长
- 确认预约：`POST /api/bookings`

### 2.4 导航

**室内**

- `GET /api/nav?seat_id=<id>&from=entry`
- 展示路径、距离、步行分钟、分步文字
- 底部主按钮：到了，签到 / 进入学习 / 结束学习

**室外**

- `GET /api/outdoor?building=<name>&lat=&lng=`
- 展示距离、方位、步行时间、分步文字
- 「使用我的位置」调原生定位
- 「在高德地图中打开」跳外部地图
- 到馆后切回室内导航

### 2.5 学习

| 功能 | 说明 |
|---|---|
| 计时 | 以服务端 `started_at` 为准，App 本地每秒刷新 |
| 学习计划 | 50 分钟专注 + 10 分钟休息 |
| 卡住了 | `POST /api/tutor/start`，两轮问答 `POST /api/tutor/answer` |
| 全局助手 | `POST /api/agent/ask` |
| 结束学习 | `POST /api/bookings/<id>/end` |
| 接棒卡 | 展示匹配理由、时长、学科、已过审 |
| 反馈 | `POST /api/relay/<pid>/feedback`，`helpful` / `unhelpful` |

### 2.6 接力池

- `GET /api/contents` 只取 `approved`
- 卡片：封面、时长、来源、标题、学科、有帮助数
- 学科筛选：全部/高等数学/英语/编程/学习方法
- 点卡片进详情/播放

### 2.7 交棒上传（P1）

- 选择视频：mp4 / mov / webm，≤ 500MB
- 表单：标题、学科、知识点、描述、来源（学生/教师）
- `POST /api/contents` multipart
- 上传进度、抽帧状态、待复核/已通过/已驳回
- 审核结果站内信通知

### 2.8 我的

| 功能 | 说明 |
|---|---|
| 封面 | 点击封面或「更换封面」上传，≤ 8MB |
| 头像 | 点击头像上传，≤ 8MB |
| 资料 | 昵称、学院、学习签名、兴趣方向 |
| 数据栏 | 场次、专注时长、交棒、接棒、有帮助率 |
| Tab | 我的场次/我的交棒/接棒记录/学习轨迹/设置 |
| 学习名片 | 可截图分享，不含社交指标 |

### 2.9 消息（P1）

- `GET /api/messages`
- 未读数、已读 `POST /api/messages/read`
- 接棒提醒、审核结果

## 3. 原生能力桥（必须实现）

鸿蒙端通过 `Web` 组件的 `javaScriptProxy` 注入 `window.Native`，Web 页面检测 `Native.available` 后调用。

| 方法 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `Native.available` | — | boolean | 是否在 App 内 |
| `Native.getPosition()` | — | `{lat,lng,accuracy}` | 室外导航定位 |
| `Native.notify(title, body, data)` | string, string, object | boolean | 本地通知：接棒/到期/审核 |
| `Native.pickMedia(kind)` | `avatar` / `cover` / `video` | `{uri,name,size,mime}` | 选图片/视频 |
| `Native.scanQr()` | — | string | 可选：扫码签到/扫码占座 |
| `Native.vibrate(ms)` | number | void | 触感反馈 |
| `Native.openUrl(url)` | string | void | 外部浏览器/地图 |
| `Native.getAppInfo()` | — | `{version,platform}` | 版本信息 |
| `Native.cacheSet(key,value)` | string, string | void | 可选离线缓存 |
| `Native.cacheGet(key)` | string | string/null | 可选离线缓存 |

### 降级规则

浏览器 / WebView 没有 Native 时：

- 定位：`navigator.geolocation`
- 通知：页面内 toast / 站内信
- 选文件：`<input type="file">`
- 震动：`navigator.vibrate`
- 扫码：隐藏入口，不摆灰按钮

## 6. HarmonyOS 实现建议

### 6.1 方案 A：Hybrid WebView HAP（推荐）

```
UIAbility
 └─ Page
     └─ Web(src = https://<域名>)
         ├─ javaScriptProxy: Native
         ├─ onBackPress → Web 返回 / 退出
         ├─ 安全区 / 状态栏
         └─ 权限申请
```

要点：

- `Web` 组件开启 DOM storage / Cookie；
- `javaScriptProxy` 注入 `Native`，方法名与上表一致；
- `onBackPress` 先调 Web 的 `history.back()`，到根页再退出；
- 首屏加载前显示 Splash；
- 权限：定位、相机（扫码可选）、通知；
- 上传：用系统文件选择器拿到 URI，再交给 Web 的 `fetch`/表单上传，或原生 `http` 上传。

### 6.2 方案 B：ArkUI 原生重写（不推荐当前阶段）

- 页面全部用 ArkTS/ArkUI 重写；
- 需要重新实现座位图、路径绘制、聊天、上传、播放器；
- 成本 5–7 天，且和 Web 双维护；
- 只有在“必须纯原生、不能 WebView”时才选。

### 6.3 能力映射

| Web 能力 | HarmonyOS 实现 |
|---|---|
| 定位 | `@ohos.geoLocationManager` |
| 本地通知 | `@ohos.notificationManager` + 用户授权 |
| 选图片/视频 | `@ohos.file.picker` / PhotoViewPicker |
| 扫码（可选） | Camera Kit + 条码识别 |
| 震动 | `@ohos.vibrator` |
| 本地缓存 | `@ohos.data.preferences` |
| 状态栏/安全区 | `window` / `WindowStage` |
| 外部地图 | `startAbility` + URI |
| 网络 | WebView 内 fetch 或 `@ohos.net.http` |
| 应用信息 | `bundleManager` |

### 6.4 权限

- `ohos.permission.INTERNET`
- `ohos.permission.LOCATION`
- `ohos.permission.APPROXIMATELY_LOCATION`
- `ohos.permission.CAMERA`（扫码可选）
- 通知授权：运行时 `requestEnableNotification`
- 相册/文件：优先用 Picker，避免申请宽泛媒体权限

> 具体权限名以你使用的 HarmonyOS SDK 版本和 DevEco 文档为准；不要申请与功能无关的权限。

## 8. 移动端交互细节

### 座位图

- 双指缩放 + 单指拖动；点击座位选中；
- 座位太小可放大；选中后底部弹窗；
- 图例固定在上方；
- 3F/教学楼切换后重新加载，不保留上一层选中。

### 底部弹窗

- 座位详情、预约表单、接棒卡、反馈都用 Bottom Sheet；
- 高度不超过 75% 屏幕；
- 有遮罩，点遮罩关闭；
- 键盘弹起时表单上推。

### 计时

- 显示 `HH:MM:SS`；
- 以前端定时器刷新，但每次从服务端 `started_at` 重算，防止后台被系统冻结后漂移；
- 结束/到期时刷新接棒卡。

### 上传

- 选文件后先展示文件名/大小/时长；
- 上传进度条；
- 失败可重试；
- 成功后跳「我的交棒」，显示待复核。

### 空状态 / 错误

- 空状态给下一步按钮（去找座/去交棒/去学习）；
- 网络错误给「重试」，不白屏；
- 权限被拒给「去设置」。

## 12. 边界

- 不做完整原生重写；
- 不做离线全量缓存；
- 不做支付、社交、关注、评论；
- 审核/编排工作台优先桌面；
- 真实推送需要 HMS Push Kit，首版用轮询 + 本地通知；
- 高德/地图能力按 SDK 可用性接，失败回退方向示意图；
- 所有演示数据仍是 seed 假数据，不要当真实校园数据。
