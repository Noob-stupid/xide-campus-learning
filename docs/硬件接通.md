# 硬件接通说明

## 代码位置

- 固件：`hardware/esp32_seat_sensor/esp32_seat_sensor.ino`
- 配置模板：`hardware/esp32_seat_sensor/secrets.h.example`
- 服务端：`services/devices.py`
- 接线与烧录：`hardware/README.md`

## 协议

```text
POST /api/sensor/device/register
GET  /api/sensor/device_config?device_id=...
POST /api/sensor/report
```

服务端返回 `{code,message,data}` 信封；`data.config` 里包含 `seat_id`、`seat_code`、`report_interval_ms`、`ir_active_high`。

## 已实测

- 注册后自动绑定第一张空闲座位（演示环境）
- 双 PIR 都遮挡 → 对应座位 `occupied`
- 第一次无人 → `pending_release`
- 连续第二次无人 → `free`
- 硬件沙盒和 HTTP 模拟都使用同一协议

## 真机步骤

1. 按 `hardware/README.md` 接线，先断电确认 5V/GND；
2. 复制并填写 `secrets.h`；
3. 烧录固件，串口查看 register/report 日志；
4. 在管理员「空间」页或 `/api/seats` 查看 `live_status`；
5. 若要绑定指定座位，在注册/配置接口中传对应 `seat_id`，或扩展管理端绑定 UI。
