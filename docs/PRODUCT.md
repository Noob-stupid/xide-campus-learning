# 《习得》产品与融合说明（给协作对端）

## 0. 一句话

**习得：从落座到学会。** Web 是作品本体，多智能体与工作流是后台能力。

- 主循环：预约 → 学习 → 卡住了辅导 → 结束/预约到期 → 从已过审内容池匹配 → 推送「接棒卡」→ 反馈。
- 供给侧：学生/教师「交棒」上传学习/教学视频 → 抽帧 → AI 初筛 → 人工帧级复核 → 入「接力池」。
- Slogan：**离座，不放学。**

## 1. 这不是三个作品拼接，是三条能力的因果链

| 原作品 | 在新项目里的角色 | 只吸收什么 | 明确不搬什么 |
|---|---|---|---|
| 校园创意文化展示站 | 交棒流水线（内容供给侧） | 视频上传、抽帧、AI 初筛、人工复核、审核状态、卡片网格、播放页 | 轮播、热门榜、点赞/收藏/评论/关注、动态、UP 主主页、整套视频站外壳 |
| 智能选座与导航 | 接棒流水线（空间需求侧） | 座位图交互、预约卡、A* 导航路径、AI 推荐理由、终端克制气质 | Vue3/Element/Fabric/ECharts 重前端、整套设备/建筑管理后台、室外导航/高德、移动端 App |
| 农技宝任务流 | 两条流水线的引擎 | 1+N 意图路由、澄清循环、苏格拉底教学循环、状态传递、异常兜底 | 农业知识库、作物诊断、超星平台外壳 |

## 2. Web-first 的边界

- 作品形态：**云上部署的 Web 应用 + 可视化 Demo 页面**。
- 智能体：Web 里的助手浮窗、推荐理由、辅导对话、工作流节点；**不是独立产品**。
- 工作流：Web 里的「编排」页面可见；不是去 AgentArts 控制台才算。
- CodeArts：开发工具，留「需求→代码→构建→修复→部署」证据。
- RDS/Redis/OBS/MaaS：支撑 Web 运行，不替代 Web 作品。

## 3. UI 吸收原则

### ✓ 采用（只借观感/交互，全部重写）

- 视频站个人主页：封面 + 头像 + 数据栏 + Tab + 卡片网格；但数据换成**学习场次/专注时长/交棒/接棒/有帮助率**，不做粉丝/获赞/浏览。
- 视频站播放页/上传页：播放器、上传进度、审核状态。
- 视频站待审列表：队列、通过/驳回、驳回原因。
- 智座座位图：缩放、拖拽、点座位看详情、状态色图例。
- 智座导航：路径、距离、步行时间、步骤列表。
- 智座 AI 推荐理由：座位推荐/接棒推荐都要给「为什么」。
- 智座终端：科技简约、克制，只借气质。

### ✗ 不采用

- 轮播图、五大分类频道、热门榜、点赞/收藏/评论/关注/动态/私信。
- 粉丝/获赞/浏览等社交指标。
- Vue3 + Element Plus + Fabric.js + ECharts + Socket.IO 重前端栈。
- 整套建筑/楼层/座位/设备/用户/学校管理后台。
- 室外导航、高德地图、移动端 App、语音/扫码/PDR/地理围栏。
- 任何 `E:\项目\...` 硬编码、mock-api 兜底、页面级独立 CSS/JS。

## 4. 必须新做的三块差异化 UI

1. **接棒卡**：学习结束后的核心物件，像票根/登机牌；带「为什么推给你」+ 复核签章。
2. **一屏帧级审核工作台**：左预览、中帧时间轴（红帧）、右 AI 理由 + 四项清单 + 通过/驳回。
3. **编排流水线看板**：五条流的节点图 + 运行轨迹 + 指标。

## 5. 设计令牌

- 主色 `#0F2A4A`；点缀 `#C98A2E`；青绿 `#0E7C6B`；背景 `#F5F7FA`；卡片 `#FFFFFF`；线 `#E4E8EF`。
- 字体：`system-ui, "PingFang SC", "Microsoft YaHei"`。
- 圆角 16px；阴影 `0 6px 24px rgba(15,42,74,.06)`。
- 风格：学术科技、克制、浅色为主；不要 AI 紫、霓虹、赛博大屏。

## 6. 对端实现时的命名/口径

- 上传 → **交棒**；收到推送 → **接棒**；内容池 → **接力池**。
- 内容状态：`processing` / `pending_review` / `approved` / `rejected`。
- 审核结论：`approve` / `reject`；帧状态：`pending` / `cleared` / `flagged`。
- 辅导只做「卡住了」的即时帮助，不做题库/刷题/通用聊天机器人。
- 任何 AI 能力必须有规则兜底，不能编造；不会就承认并转人工建议。

## 7. 当前 MVP 主线（优先级）

1. 登录 + 首页 + 座位地图 + 预约 + 导航
2. 签到 + 学习计时 + 「卡住了」辅导 + 结束/到期
3. 交棒上传 + 抽帧 + AI 初筛 + 一屏帧级复核 + 入池
4. 接棒推送 + 接力卡 + 反馈
5. 编排看板 + 指标
6. 设备模拟器（可选，P1.5）
